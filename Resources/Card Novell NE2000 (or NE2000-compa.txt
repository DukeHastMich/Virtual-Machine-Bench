Here’s a clean function map of a classic late-1980s / early-1990s NE2000-class Ethernet card, broken into the systems/components that need emulation:1. DP8390 (or compatible) Network Interface ControllerCore of the cardCommand Register (CR)
Page Select (Page 0 / 1 / 2)
Interrupt Status & Mask registers
Data Configuration, Transmit Configuration, Receive Configuration
Boundary Pointer, Current Page, Next Page
Remote DMA logic (read/write packet data)
Local DMA (internal buffer management)
Transmit and Receive state machines
Collision detection / backoff
CRC generation / checking
FIFO (internal to the chip)

This is the largest and most important block.2. Packet Buffer RAMUsually 8 KB or 16 KB of dual-ported SRAM
Mapped as ring buffer (transmit and receive pages)
Accessed via the DP8390’s remote DMA
Needs correct page wrapping and boundary pointer behavior

3. Station Address PROM / EEPROM16-byte (or 32-byte on some clones) PROM at I/O base + 0x00
Contains:6-byte MAC address (repeated)
NE2000 signature bytes (0x57, 0x57)
Checksum

Many drivers read this PROM to identify the card and get the MAC
Must be emulated accurately (including the odd “double MAC” layout)

4. I/O Decoding & Configuration LogicAddress decode for the chosen I/O base (0x300, 0x320, 0x340, 0x360, etc.)
Optional shared-memory window decode (some clones)
Jumper or soft-configurable IRQ and I/O base
Reset logic (NE2000 has a specific reset sequence)

5. Interrupt GenerationIRQ line driven by the DP8390’s interrupt output
Must correctly raise/lower the chosen IRQ (usually 3, 5, 10, 11, 12, or 15)
Edge-triggered behavior matching ISA

6. Boot ROM Socket (optional but common)8 KB or 16 KB EPROM/ROM socket
Mapped into the ISA memory space (commonly C800h, D000h, etc.)
Contains network boot code (RPL, PXE precursor, or vendor-specific)
Needs a simple ROM image + decode logic if you want boot-from-network support

7. Media Interface (less critical for basic emulation)10BASE-T / 10BASE2 / AUI selection logic
Link status / activity LEDs (can be simple status bits)
Most pure software emulators ignore the actual PHY and just deliver frames

8. Bus Interface GlueISA 16-bit data path
I/O and memory cycle timing
Ready / wait-state generation (some cards inserted waits)
