# VMBS -> VMB NE2000 integration CP24

Source authority: Library `VMB-MATERIALIZATION-CP01-2026-09-16.zip` (newer than GitHub working-beta at the time of that checkpoint).

This integration replaces the legacy direct NE2000 construction block in `MachineMaterialization.vb` with the CAD-derived generated board build path.

`ISA8_Ethernet.GeneratedBoard.vb` is generated by VMBS from the original KiCad board.
`VmbGeneratedBoardRuntime.vb` adapts stable VMBS MODULE_ID/configuration output to current VMB classes.

Important compatibility boundary: current `Ne2000Isa` is a fat board-level implementation. CP24 uses it only for VMBS `VMB_DEFAULT_EXECUTION`, where boot ROM defaults disabled. It does NOT claim full U2 flash/U3 EEPROM/boot-ROM fidelity. Full selectable execution remains TITS(up) until skinny component modules or an explicitly proven reusable contraction are implemented.

Static validation passes. No .NET/VB compiler exists in the assistant sandbox, so Windows/Visual Studio compile and guest runtime remain required acceptance tests.
