Primary controller reference
  S3 Incorporated, 86C928 GUI Accelerator Data Book
  https://www.dosdays.co.uk/media/s3/928/86C928_Datasheet.pdf

  Relevant sections used by DiamondStealthPro928.vb:
    Section 6, VGA Standard Register Descriptions
      Input Status 0/1; Sequencer reset, clocking and memory mode; CRTC blank,
      display, retrace and overflow timing; Graphics Controller read/write,
      odd/even and chain addressing; Attribute Controller operation.
    Section 7, S3 VGA Register Descriptions
      CR31-CR35 memory, compatibility and lock controls.
    Sections 8-9, System Control/System Extension Registers
      CR45-CR4F hardware cursor; CR50/CR51 display/engine controls; CR55 Bt485
      external DAC and cursor wiring; CR5D/CR5E timing overflow.
    Section 10, Enhanced Commands
      Graphics-engine registers, status, pixel length and command behavior.
    Section 11, Enhanced Mode Programming
      Cursor alternating AND/XOR word stream, color stacks and storage layout.

Primary RAMDAC reference
  Brooktree Corporation, Bt485A 170 MHz Monolithic CMOS True-Color RAMDAC,
  document L485A01 Rev. B
  https://www.dosdays.co.uk/media/brooktree/BT485_Datasheet.pdf

  Relevant sections used by DiamondStealthPro928.vb:
    MPU Interface and Accessing the Cursor RAM Array
      Palette/component phases, address auto-increment and planar cursor RAM.
    Power-Down Mode and Frame Buffer Clocking
      DAC output power state with retained MPU/register access.
    Frame Buffer Pixel Port Interface, Tables 3-9
      VGA/pixel PORTSEL, 4/8/15/16/24-bit formats, nibble order, BGR packed
      order, true-color palette bypass, sparse/contiguous indexing and mask.
    Cursor Operation, Figure 6, Figure 7 and Table 10
      Cursor modes, planar pixels, lower-right origin and position latch at CYHR.
    Internal Registers, pp. 24-32
      Command registers 0-4, status/signature, cursor address and X/Y registers.
